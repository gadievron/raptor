# Unicode smuggling / tag character injection patterns.
# These detect Unicode code points used to hide instructions from human
# review while remaining parseable by LLM tokenisers.

# Zero-width/bidi classes are spelled as \uXXXX ESCAPES, never raw
# codepoints: the literal characters are invisible in an editor, so
# a reviewer cannot tell the class from quoted blanks — and an
# accidental "cleanup" would silently disable the defence (the
# cc_trust._EXTRA_STRIP doctrine). The loader compiles each line as
# a regex, so escape spellings match identically.
# Unicode tag characters (U+E0001..U+E007F) — invisible "language tags"
# that some tokenisers decode as ASCII. Used in the "Unicode tag smuggling"
# attack (Trail of Bits, 2024).
[\U000e0001-\U000e007f]

# Invisible formatting / zero-width characters used to hide text or
# disrupt visual review.
[\u200b-\u200f\u2060-\u206f\ufeff]

# Homoglyph-rich blocks used to fake identifiers / URLs in prompts.
# Cyrillic lookalikes for Latin a/c/e/o/p/s/x.
[аеорсхАВЕНОРСТХ](?=[a-zA-Z])

# Right-to-left override (U+202E) and related BIDI overrides — used to
# make "mark as safe" render visually while the logical text says the
# opposite.
[\u202a-\u202e\u2066-\u2069]
